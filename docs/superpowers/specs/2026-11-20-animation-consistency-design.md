# 애니메이션 비율 통일 설계

## 왜

`assets/phoebe`의 동작들은 서로 다른 정지 그림에서 출발해 등신과 머리 크기가 제각각이다.
idle(약 2등신)에서 걷기(약 3등신)로 넘어갈 때 머리가 갑자기 작아지고, 정면에서 옆모습으로 한 프레임 만에 바뀐다.
모든 동작이 같은 캐릭터로 보이고 동작 사이가 자연스럽게 이어지게 한다.

## 목표와 범위

- 바닥 동작(서기, 걷기, 말하기, 생각, 앉기, 눕기·잠자기, 기어가기, 올려다보기, 착지)은 같은 등신·같은 머리 크기.
- 서기↔걷기, 서기↔앉기, 앉기↔눕기, 눕기↔잠자기 사이에 전환 동작이 있다.
- 공중·벽 동작(버둥거리기, 떨어지기, 끌려가기, 벽·천장)은 머리 크기만 바닥 동작에 맞춘다.
- 하지 않는 것: LoRA 재학습, 프레임 크기(128px) 변경, 공중·벽 동작 재생성, placeholder 캐릭터 변경.
- 피할 것: 동작마다 손으로 고른 배율. 다시 어긋나는 원인이다.

## 검토한 방법

1. **배율만 다시 맞추기.** 머리 크기 기준으로 확대·축소. 빠르지만 걷기는 1.4배가 필요해 틀을 넘고 등신 차이는 그대로 남는다. 바닥 동작에는 부적합.
2. **정면 걷기.** 서 있는 그림을 시작·끝으로 제자리 걷기 영상 하나. 이음매는 없지만 게걸음이 되고 다른 동작은 해결하지 못한다.
3. **기준 그림에서 이어 만들기 (채택).** 서 있는 그림 하나에서 Wan I2V로 전환 영상을 만들고, 그 한 프레임을 다음 반복 동작의 시작·끝 장면으로 쓴다. 시험 생성(서기→걷기, 서기→앉기)에서 비율이 유지되는 것을 확인했다.

공중·벽 동작은 끌려가거나 던져질 때만 나와 장면이 끊겨도 자연스러우므로 1번으로 충분하다.

## 설계

**생성 순서** (모두 `set_stand_s100` 한 장에서 출발)

```
서기 ─ 돌아서기 ─▶ 걷기 반복
     ─ 앉기 ────▶ 앉기 반복 ─ 눕기 ─▶ 기어가기 반복
     │                              └ 잠들기 ─▶ 잠자기 반복
     ─ 생각 자세 ─▶ 생각 반복
     ─ 올려다보기 (서기로 돌아오는 반복)
     ─ 웅크렸다 일어서기 (착지에 사용)
```

전환 영상은 자세가 자리 잡은 프레임까지만 쓰고, 그 프레임이 다음 반복 동작의 기준이 된다. 되돌아가는 전환은 같은 프레임을 거꾸로 나열한다.

**자르기 (`tools/imagegen/build.py`)**
바닥 동작은 모두 같은 480px 영상 좌표계에 있으므로 **배율 하나와 발 기준선 하나**를 공유해 자른다. 동작별 목표 키는 없앤다.
공중·벽 동작은 동작별 배율을 유지하되 머리 폭이 바닥 동작과 같아지도록 값을 다시 잡는다.

**엔진**

- 동작 길이를 프레임 한 바퀴의 정수배로 맞춘다. 반복이 기준 프레임에서 끝나야 전환과 이어진다.
- 동작에 선택 항목 `intro = true`를 둔다. 이 동작을 시작할 때 이동 방향을 미리 정하고, 바로 다음 동작은 방향을 다시 바꾸지 않는다(돌아선 뒤 반대로 걷는 일 방지).

**동작표 (`assets/phoebe/actions.toml`, build.py가 생성)**
`stand → to_walk → walk → from_walk → stand`, `stand → sit_down → sit → stand_up → stand`,
`sit → lie_down → creep`, `creep → doze_off → lie → wake_up → creep`, `creep → get_up → sit`.
그림이 없는 `sit_spin`은 phoebe 동작표에서 뺀다.

## 만드는 사람에게 맡기는 것

프롬프트 문구와 시드, 전환을 끊는 프레임 번호, 공중·벽 동작의 배율 값. 결과는 눈으로 확인해 고른다.
